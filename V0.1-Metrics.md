# V0.1 retrieval metrics

Measured locally on 8 September 2026. The corpus contains all 35 multi-paragraph
Wikipedia articles in Stanford's SQuAD 2.0 development set: 1,204 paragraphs became
2,290 ordered Docling evidence regions. The evaluation contains 420 questions: 140
answerable, 140 indexed-article adversarial, and 140 missing-source.

## Prompt-pass architecture comparison

The comparison below holds the BM25 threshold at `5.0` and uses exactly the same
questions and index for both paths. The
answerable sample is deterministic: four answer-bearing questions from each document.
The prompt pass preserves the grammatical question for dense BGE retrieval, copies
content terms to BM25, and requires numbers and multiword proper names to occur somewhere
inside the dense region set. It does not call a model or rewrite the query.

| Measure | Whole question to both encoders | Deterministic prompt pass |
| --- | ---: | ---: |
| Answer-bearing evidence | 130/140 (92.9%) | 130/140 (92.9%) |
| Expected source present | 134/140 (95.7%) | 134/140 (95.7%) |
| Correct source first | 131/140 (93.6%) | 133/140 (95.0%) |
| Indexed-article adversarial rejection | 4/140 (2.9%) | 18/140 (12.9%) |
| Missing-source rejection | 38/140 (27.1%) | 62/140 (44.3%) |
| Combined unanswerable rejection | 42/280 (15.0%) | 80/280 (28.6%) |
| Mean / p50 / p95 latency | 16.48 / 16.04 / 20.92 ms | 13.95 / 13.64 / 17.08 ms |

The latency difference is ordinary warm-run variation, not a claimed speedup. The
accuracy result is the useful change: the pass rejects 38 additional unsupported
questions without losing an answer-bearing case on this sample. Exact anchors constrain
the dense set rather than every final chunk; requiring them on every chunk reduced
answer-bearing evidence to 125/140 and was rejected.

## Retrieval controls

Dense similarity admits every region at or above `0.55`. FastEmbed `Qdrant/bm25` uses
English stemming, `k=1.2`, `b=0.75`, `avg_len=256`, a 40-token maximum, and Qdrant's IDF
modifier. BM25 searches only the dense region IDs and accepts scores at or above `12.5`.
There is no whole-base fallback, fusion, reranker, verifier, or query-time LLM.

The prompt-pass threshold sweep uses the same saved 420 results. Higher cutoffs are
calculated directly from Qdrant's ordered BM25 scores:

The selected V0.1 operating point is `12.5`: 124/140 answer-bearing, 127/140 correct
source first, and 131/280 unanswerables rejected. Compared with `5.0`, it trades six
answer-bearing results for 51 additional correct rejections.

The exact no-loss ceiling is `6.15401`; moving above it removes the first previously
retrieved answer. If answerable and unanswerable questions are weighted equally, the
best observed balance is around `16.99`: 111/140 answer-bearing and 166/280 rejected.
The score distributions still overlap completely. The highest false adversarial score
is `62.636112`, above the highest answer-bearing score of `60.457485`, so no BM25
threshold can reject every unanswerable while retaining even one measured answer.

## Ingestion

The first generation took 92.0 seconds (24.9 regions/s); a repeated cold-process run
took 80.47 seconds (28.46 regions/s). Cached TEI artifacts reached ready in about 1.6
seconds. The first full retrieval took 145.4 ms; the next 20 averaged 18.0 ms. Source
SHA-256 values are `80a5225...77182d8` for dev and `68dcfbb9...dede002` for train.

Raw prompt-pass evidence for all 280 unanswerable cases is in
